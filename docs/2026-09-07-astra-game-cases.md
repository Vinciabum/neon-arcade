## 3. 네온 아케이드에 낼 3개 (제안)

세 개 다 **에셋 0 · 브라우저 단독 · 한 손 조작**을 지킨다. 기존 `games.json` 구조를 안 건드린다.

### A. 물범 쓰다듬기 (`seal-petting`) — 물범바위 v2
- 뿌리: #281(드래그 제스처) + #275(슬라임) + #357(동물 소리)
- 한 입력. 마우스/터치 드래그로 물범을 쓰다듬는다. 세게 하면 놀라고, 결대로 하면 눈을 감는다.
- 성공 지표: 평균 체류 60초 이상. (지금 물범바위는 한 입력 게임 v1 — 그 위에 얹는다)
- 예상: 20~40분 / $2~5 범위 (#95 $1.84·10분, #424 $20·80분 사이)

### B. 조각 마을 (`patchwork-town`) — 코지 전술/배치
- 뿌리: #365(타일 회전) + #274(마을) + #378(블록 세계)
- 펠트 조각을 돌려 끼워 마을을 만든다. 실패 없음, 되돌리기 무한.
- 성공 지표: 재방문율. 저장 상태 localStorage.

### C. 30초 물범 (`30sec-seal`) — 숏폼 연료
- 뿌리: #326(30초 미니게임) + #153(3회 규칙 + 엔딩) + #264(5분 제작)
- 30초 안에 끝나는 미니게임을 **주 1개씩 양산**한다. 각 게임이 숏폼 1편.
- 성공 지표: 편당 제작 60분 이하. 이게 넘으면 포맷을 줄인다.

2. **방치 금지.** #298은 대충 던지고 두고 봤다가 1회로 쿼터를 끝냈다.
3. **GUI 앱 조작을 시키지 않는다.** Blender/Clip Studio 조작이 쿼터 소진 사례를 독식한다(#266은 10분에 소진). 코드 생성만 시킨다 — #367이 씬·음악·효과음을 전부 코드로 만들었다.
